The generic AI look Avoid

Dark indigo gradient, particles, gradient text and an "AI-powered" headline. It looks like every AI startup, and a WSU study found the word "AI" in product copy lowers purchase intent, more so for higher-stakes purchases. Lead with outcomes like "exact price, answered 24/7" and explain the AI in the supporting copy.

How to implement it in the repo

Your stack is Next 14, React 18 and Tailwind 3. Most registries now default to React 19 and Tailwind v4, so every install below should be checked for v4-only classes like size-* and bg-linear-*.

components.json has rsc: false, so add "use client" to each animated file by hand.

Rules that keep it fast

  • The H1 and hero image render on the server with no fade-in. Target LCP under 2.5s.
  • At most one canvas or WebGL element above the fold; ideally none.
  • Load the voice orb, beams and feed with next/dynamic and start them when scrolled into view.
  • One useReducedMotion() hook from motion that every animated section reads.
  • Pick one of framer-motion v12 or motion and remove the other.
  • Stay on HeroUI 2.8. v3 needs React 19 and Tailwind v4.

Fix before launch

  • Remove "Google Guaranteed" and the "$2,000 guarantee" from the H1 badge, the trust grid and the SEO description. Use "Google Verified" only if your Local Services Ads profile shows it.
  • Replace example prices, stats and reviews with real data.
  • Get a real call recording with customer details removed for the voice demo.
  • Collect before/after pairs and crew photos with consent.
